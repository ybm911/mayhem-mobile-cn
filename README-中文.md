## 一、这到底是个什么东西？

一句话：**把你插在电脑上的 HackRF（或 RTL-SDR），变成一个跑在浏览器里的无线电接收机。**

它原本是安卓上 PortaPack Mayhem 固件的各种 App（收飞机、收船、收气象站、收卫星、发莫尔斯电码……）。
这个项目把它们移植到了网页上，靠的是浏览器的 **WebUSB** 能力——网页可以直接读写 USB 设备，**不用装驱动**。

所以你在网页上调频率、看频谱瀑布图、听声音，背后真的是你的 HackRF 在收信号。

### 三个最常见的误解

| 误解 | 事实 |
|---|---|
| 网页自己在收无线电 | 不是。网页只是"遥控器"，硬件还是你插的那台 HackRF |
| 装了驱动才能用 | 不用。WebUSB 是浏览器直接跟 USB 说话 |
| 什么浏览器都行 | 不行。**只有 Chrome / Edge**（含安卓）。Safari、Firefox 不支持 WebUSB |

## 三、怎么跑起来

```bash
cd /Users/elliot/Documents/Program/HackRF
./run_mayhem.sh           # 起一个本地 http 服务
# 然后浏览器打开  http://127.0.0.1:5173
```

**为什么不能双击 index.html？**
页面用 `<script type="module">` 加载 JS。ES module 受同源策略限制，`file://` 协议会被浏览器直接拒绝。
所以必须起一个本地 http 服务——这就是 `run_mayhem.sh` 存在的唯一原因。

**连上硬件的步骤：**
1. 用 **Chrome 或 Edge** 打开（Safari 不行）
2. HackRF 插上 USB（手机需要支持 OTG 的数据线，很多充电线只能供电不能传数据）
3. 点右上角 ☰ → **连接** → 在弹出的设备选择框里选你的 HackRF
4. 状态灯变绿 + 顶栏显示板卡型号，就成功了
5. 点「日志」可以看到完整的握手过程，出问题先看这里

> 如果你用的是 PortaPack，要先把它切到 **HackRF 模式**，否则认不出来。

## 四、数据是怎么流动的（看懂这张链路，代码就通了一半）

```
HackRF (USB)
   │  批量传输，端点 0x81
   ▼
IQ 字节流 [I0,Q0,I1,Q1,...]  每对是一个 8 位有符号复数采样点
   │
   ├─► dsp.worker.ts（Web Worker 独立线程）
   │      变频 / 滤波 → 解调(AM/FM/SSB) → 协议解码(AIS/APRS/POCSAG...)
   │      │
   │      ├─► 频谱数据 ──► scope.ts 画频谱 + 瀑布图
   │      ├─► 音频 PCM ──► audio-worklet.js ──► 扬声器
   │      └─► 解码结果 ──► main.ts 更新界面
   │
   └─► （控制命令反向走：设频率 / 设增益 / 切换收发）
```

**几个关键点：**

- **IQ 是什么**：无线电信号下变频后拆成两路（同相 I、正交 Q），合起来是一个复数。
  所有解调、滤波、FFT 都建立在它之上。采样率 4 MS/s 时每秒 1600 万字节。

- **为什么 DSP 要放 Worker**：主线程要画界面、响应点击。把 1600 万字节/秒的运算塞进去，界面会直接卡死。
  Worker 是独立线程，算完 postMessage 回主线程。

- **为什么声音用 AudioWorklet 而不是 `<audio>`**：要做到低延迟、不爆音。
  Worklet 跑在音频线程上，内部维护环形缓冲区，DSP 那边抖一下声音也不会断。

- **为什么改频率不立刻生效**：控制传输（设频率）不能和数据传输同时进行，
  所以代码里区分了 `targetFreqHz`（用户想要的值）和 `appliedFreq`（已写进硬件的值），
  真正下发要等两个数据包之间的空隙——见 `hackrf.ts` 的 `applyPending()`。

## 六、名词表（看代码会反复遇到）

| 词 | 含义 |
|---|---|
| **IQ** | 信号的同相/正交两路，复数采样点 |
| **FFT** | 快速傅里叶变换：把"随时间变化的信号"变成"各频率上有多少能量" |
| **瀑布图** | 每帧频谱画成一行像素，时间往下流，看信号随时间的变化 |
| **Msps** | 每秒百万采样点（Mega-samples per second） |
| **LNA / VGA** | 两级增益：低噪声放大器 / 可变增益放大器 |
| **AGC** | 自动增益控制 |
| **静噪 (SQL)** | 没信号时静音，有信号才放声 |
| **CTCSS** | 亚音静噪，对讲机常用的"编码静噪" |
| **DXCC** | 业余无线电的国家/地区列表，靠呼号前缀判断 |
| **ADIF** | 通联日志的通用文件格式 |
| **APRS** | 业余无线电的位置/报文系统（144.39 MHz） |
| **AIS** | 船舶自动识别系统（162 MHz） |
| **ADS-B** | 飞机广播的位置/高度报文（1090 MHz） |
| **rtl_433** | 开源项目，解码 433/315 MHz 的各种廉价无线设备（胎压、气象站…） |
| **TLE** | 卫星轨道参数，用来算卫星什么时候飞过头顶 |

## 七、我改了什么 / 没改什么

**改了：**
- 界面文字译成中文（约 1340 处，在 `src/` 的 UI 层）
- 每个源码文件加了中文文件头说明；`fft.ts` / `radio.ts` / `hackrf.ts` / `theme.ts` 加了行内中文注释
- `index.html` 中文化 + 逐段注释；`styles.css` 加了头部说明和段落注释
- 构建加了 `--charset=utf8`，让产物里是真正的中文（而不是 `\uXXXX` 转义）

**没改（重要）：**
- 任何一行代码逻辑
- `src/dsp/` 下的解码器输出值 **保持英文**。因为那些是协议数据（比如 `type:'aircraft'` 是
  主线程和 Worker 之间的消息标识），翻译会直接把通信协议搞断
- RTL-SDR 驱动、DSP 算法、测试逻辑

**验证方式**（改动后有全套保障）：
```bash
cd mayhem-mobile-src/web
npm run check    # TypeScript 类型检查，0 错误
npm test         # 50+ 个 DSP 单元测试，全部通过
```

## 八、新增功能：原样回放任意 IQ（录制 → 发射）

原项目只有「把 IQ 录成 .c8 文件下载」，发射那边也没有接上回放的入口。这一版把两头接上了。

**在哪用**：启动器 → **抓取**（标题已改成「录制原始 IQ · 原样回放任意 IQ」）。

**怎么用**（以 434.05 MHz 录 10 秒为例）：

1. 频率调到 434.050 MHz
2. 秒数框填 `10` → 点 **● 录 10 秒**（到点自动停，并自动载入待回放）
3. 点 **▶ 发射回放**；想让它一直循环就先点 **循环**，再发射
4. 中途停止点 **■ 停止**

也可以回放外部文件：最下面的文件选择框导入 `.c8 / .cs8 / .bin / .raw`，
填好采样率（Msps）后同样点 **▶ 发射回放**。导入的文件没有 .txt 附属文件，
所以频率用当前频率、采样率用手填的值。

**代码改了哪几处**（想看实现就搜这些）：

| 文件 | 改动 |
|---|---|
| `src/dsp/capture.ts` | 新增 `load()`：把 .c8 读回内存，解析 .txt 附属文件里的 `center_frequency` / `sample_rate`，用 transfer 把字节交给主线程；`start()` 加了 `seconds` 参数（定时自动停） |
| `src/dsp.worker.ts` | `capture` 命令新增 `load`，`start` 透传 `seconds` |
| `src/tx.ts` | `replay()` 支持重复次数（`repeats = 0` 表示一直循环） |
| `src/main.ts` | 「抓取」页面新增：定时录制、回放面板（时长/频率/采样率）、次数与频率来源选择、发射增益与放大器、导入外部文件、状态栏与停止按钮 |

回放是**字节原样送进 DAC**：不解调、不再调制、不过滤，
所以录到的噪声、直流偏移、邻台干扰会一起发出去——这就是「原样」的意思。

## 九、合规提醒

HackRF 能发射，RTL-SDR 不能。这个项目里发射功能是**受管制**的：
- 必须先在设置里打开发射开关
- 发射前要确认安全提示
- 发射需要合法的业余电台执照，且只能在执照允许的频段内操作

**在中国境内，未经批准擅自设置、使用无线电台（站）是违法的。**
收听没问题，发射请务必先取得执照和设台许可。代码里那些安全闸门请不要绕过。
